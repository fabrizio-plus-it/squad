# Skyone Agent Squad — instruções de integração
Este arquivo é instalado como `AGENTS.squad.md`, deliberadamente sem sobrescrever um `AGENTS.md` existente.

Para ativar estas orientações no Codex, acrescente ao `AGENTS.md` do projeto uma instrução para ler `AGENTS.squad.md` ao iniciar trabalhos do squad, ou consolide manualmente as duas políticas.

- Antes de executar: consultar o ID da tarefa ClickUp, o estado do Git e as instruções preexistentes no repositório.
- Não inventar requisitos ou assumir aprovação. Solicitar aceite humano do escopo e de alterações materiais.
- Não realizar push, merge, deploy, publicação Skyone nem ações destrutivas sem autorização explícita.
- Não registrar senhas, tokens, cookies, PII ou dados de candidatos em arquivos de contrato, prompts ou logs.
- Handoff entre agentes deve conter tarefa, versão de contrato, ambiente, pré-condições, evidências, riscos e rollback.
- As skills instaladas são procedimentos de agente, não processos autônomos nem permissões técnicas.
- A skill skyone-engineer permanece estritamente somente leitura na v0.1.
